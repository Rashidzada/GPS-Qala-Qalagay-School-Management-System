QUICK START INSTRUCTIONS:
-------------------------
1. Extract this folder onto your Desktop or Drive (e.g. C:\GPS_Qala_Qalagay).
2. Double-click 'gps_setup.bat' to initialize the environment and load the official
   database (Primary Classes: Class 1st to Class 5th, with all active student records).
3. Double-click 'gps_run.bat' to launch the system.
4. Your browser will open automatically at:
   http://127.0.0.1:8000/
